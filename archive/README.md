# SmartWorkforce — Historical Archives & Preserved Snapshots

This directory houses preserved historical backups, schema migration snapshots, and early development artifacts accumulated during previous phases of the SmartWorkforce project.

> [!NOTE]
> None of the files in this directory are active runtime dependencies. They are preserved for auditability, historical tracing, and recovery.

---

## Catalog of Preserved Archives

### 1. `archive/backups/phase2/`
- **Origin**: Formerly `.backup_phase2/`
- **Contents**:
  - `database.js`: Early SQLite schema and query methods prior to multi-tier hierarchy.
  - `server.js`: Initial single-portal server prototype.
  - `script.js`: Monolithic frontend script prior to modular portal separation.
  - `package.json`: Phase 2 manifest snapshot.

### 2. `archive/backups/pre_auth_db_snapshots/`
- **Origin**: Formerly `.backup_pre_auth/`
- **Contents**:
  - Incremental SQLite database snapshots (`smartworkforce_pre_migration_*.db`) automatically generated by `database/migrate.js` prior to transactional schema mutations.
  - Preserves cold-state baseline data points across development milestones.

### 3. `archive/backups/pre_reorg/`
- **Origin**: Formerly `.backup_pre_reorg/`
- **Contents**:
  - Snapshot of the application root files before frontend separation into dedicated `/login`, `/admin`, and `/employee` portals (`analytics.js`, `database.js`, `index.html`, `script.js`, `server.js`, `style.css`, `office_building.jpg`).
  - Contains duplicate preservation subdirectory `root_files_backup/`.

### 4. `archive/scratch/`
- **Origin**: Formerly `scratch/`
- **Contents**:
  - `test_employee_portal_e2e.js`: Early end-to-end diagnostic script.
  - `test_login_diagnosis_isolated.js`: Login flow diagnostic test.
  - `verify_employee_portal.js`: Personal employee portal verification script.
